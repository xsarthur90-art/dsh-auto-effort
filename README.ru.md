# dsh-auto-effort · Автоматическое усилие

Перестаньте выбирать усилие вручную. Установите плагин один раз — и **DeepSeek будет выбирать его для каждого сообщения**.

Что-то не работает? [Создайте issue](https://github.com/xsarthur90-art/dsh-auto-effort/issues/new/choose) — укажите версию плагина и последние строки из `~/.dsh/auto-effort.log`.

## Дешевле, быстрее, спокойнее — расходы на виду, переключать можно когда угодно

![Меню «Модель» со строкой «Автоматическое усилие»](https://cdn.jsdelivr.net/npm/dsh-auto-effort@0.2.5/docs/menu-ru.png)

- **Дешевле**: выбор усилия вручную обычно означает выбор неверного уровня — слишком низкий ведёт к переделкам и лишним тратам, слишком высокий сжигает токены. Автоматика добавляет всего около `$0.0002` за сообщение в непиковые часы и около `$0.0004` в пиковые.
- **Быстрее**: выбрать вручную — два клика и 2–3 с; слишком низкий уровень означает переделку работы, слишком высокий — потерянное время на рассуждения. Автоматика добавляет только около **0,7 с** на сообщение.
- **Спокойнее**: больше не нужно взвешивать «low или max» для каждого сообщения и ловить себя на «ой, не то усилие». Просто скажите, что нужно, — усилие подстроится. **Никаких переживаний!**
- **Расходы на виду**: строка в меню показывает срабатывания в этой беседе, стоимость и время выбора, а страница плагина ведёт общий итог.
- **Переключать можно когда угодно**: не нужно — выключите, нужно — включите снова.

![Страница плагина с общими итогами](https://cdn.jsdelivr.net/npm/dsh-auto-effort@0.2.5/docs/plugin-page-ru.png)

## Как он выбирает усилие

Плагин подключается к последней модели DeepSeek. Он суммирует беседу и в фоне ведёт карточку размером не более 120 символов. При каждом отправленном сообщении он читает это сообщение и карточку, а затем выбирает одно из четырёх усилий. Карточка фиксирует, что происходит в беседе и что осталось сделать, поэтому «хорошо, давай» оценивается по незавершённой работе, а не по собственной длине.

| Усилие | Для чего его выбирает DeepSeek | Измеренный пример |
|---|---|---|
| `off` | беседа, подтверждения, поиск информации, правка конфигурации, выполнение команд | покажи текущий каталог |
| `low` | небольшие правки, переименования, уборка, применение известного шаблона | переименуй эти переменные единообразно |
| `high` | анализ, отладка, объяснение причин, нетривиальный код | помоги разобраться, почему этот подход медленный |
| `max` | архитектура, сравнение вариантов, многокритериальные компромиссы, сложные баги | проследи по журналу до корневой причины эту плавающую утечку памяти |

> DeepSeek документирует параметр силы (`low` / `high` / `max`, а также `off` для отключения рассуждений), но **не говорит, какая задача требует какого усилия**. Таблица выше — это то, что модель-арбитр DeepSeek предлагает сама, без участия человека; каждый пример проверен на реальном вызове арбитра.

## Стоимость

Плагин выполняет одну оценку и одно обновление карточки на каждое сообщение. Оценка всегда отвечает одним словом — off, low, high или max, — поэтому почти не расходует токены и занимает около 0,7 с. Карточка ограничена 120 символами, поэтому не растёт вместе с беседой. Карточка пишется в фоне после ответа и никогда не увеличивает ваше ожидание.

| На сообщение | Непиковые часы | Пиковые часы |
|---|---|---|
| Оценка + карточка | около `$0.0002` | около `$0.0004` |

## Установка

Три способа, выберите один.

**1. Пусть DSH установит сам** — отправьте это в любой беседе:

```
Установите плагин dsh-auto-effort
```

**2. Терминал** — если установлен CLI DSH:

```
dsh plugin --profile web add dsh-auto-effort
```

**3. Страница плагинов** — откройте **Плагины** в боковой панели, найдите `dsh-auto-effort`, нажмите **Установить**.

Строка, начинающаяся с `+ dsh-auto-effort`, означает, что всё получилось.

**После установки или обновления плагина перезапустите DSH.**

Если хотите узнать перед обновлением, что изменилось, загляните в [CHANGELOG.md](https://github.com/xsarthur90-art/dsh-auto-effort/blob/main/CHANGELOG.md).

## Включение и выключение

**Включение**

Он работает с момента установки: новая беседа сразу начинает выбирать усилие автоматически, а **уже открытая беседа — после перезапуска DSH.**

**Выключение**

- Выключите **Автоматическое усилие** в меню «Модель»: только для этой беседы.
- Выберите любое усилие вручную: это тоже отключает автоматику в текущей беседе.
- Отключите плагин на странице плагина: автоматический выбор прекратится во всех беседах.

## Конфигурация

Обычно здесь ничего не нужно менять. Всё ниже — для тонкой настройки и устранения неполадок; значения по умолчанию подходят почти всем.

| Поле | По умолчанию | Значение |
|---|---|---|
| `enabled` | `true` | главный переключатель; если выключен, логика оценки не загружается |
| `mode` | `auto` | значение по умолчанию для новых бесед: `auto` оценивает каждое сообщение, `manual` только передаёт управление вручную; переключатель в меню меняет текущую беседу |
| `levels` | `["off","low","high","max"]` | усилия, которые может использовать автоматический режим |
| `judgeModel` | `deepseek-flash` | модель для оценки; пустое значение или `model` — оценивать моделью этой беседы |
| `timeoutMs` | `3000` | тайм-аут оценки; при тайм-ауте используется текущее усилие |
| `defaultLevel` | `null` | запасное усилие при сбое оценки; `null` означает, что текущее усилие сохраняется |
| `requireMaxForUpgrade` | `false` | по умолчанию выключено, поэтому автоматика может выбрать верхний уровень `max`; если включить, автоматика останавливается на `high`, а `max` выбирается только вручную |
| `logFile` | `null` | путь к журналу; `null` означает `~/.dsh/auto-effort.log` |
| `cardInputChars` | `600` | сколько символов ответа читает составитель карточки; меньше — дешевле, но точность может упасть |
| `cardMaxChars` | `120` | ограничение текста самой карточки; меньше — дешевле, но точность может упасть |
| `debug` | `false` | подробное журналирование, включая необработанный вывод оценки |

## Отправка во время выполнения хода

**Настройки → Общие → Отправлять поведение во время занятости** определяет, что происходит с сообщением, отправленным, пока ответ ещё пишется:

- **Направить** — сообщение присоединяется к выполняющемуся ходу и сохраняет его усилие.
- **Очередь** — ведёт себя точно как обычное сообщение.

## Если ничего не происходит

1. Убедитесь, что плагин **включён** на странице плагина (**Плагины → Установленные плагины**).
2. Если беседа уже существовала на момент установки, перезапустите DSH один раз.
3. Проверьте, что **Автоматическое усилие** в меню «Модель» всё ещё включено, — ручной выбор усилия отключает автоматику только в этой беседе.
4. Откройте журнал `~/.dsh/auto-effort.log` — на каждое сообщение там пишется строка `turn N judging …`.
5. Если ход завершился ошибкой API или оценка три раза подряд не удалась, плагин приостанавливает эту беседу, а над полем ввода появляется полоса с причиной. Нажмите в ней **Включить снова** или выключите и снова включите переключатель — перезапуск не нужен.

## Удаление

**Плагины → Установленные плагины → dsh-auto-effort → Удалить.** Оценка прекращается; добавленная плагином конфигурация очищается.

## Разработка

- Исходники: `index.js` (хостовая часть), `client.js` (переключатель в меню «Модель» и баннер паузы), `judge.js` (два вызова оценки), `config.js` (проверка без зависимостей), `schema.js` (схема конфигурации), `stats.js` и `server.js` (локальный счётчик стоимости и переключатель для каждой беседы, стоящие за цифрами).
- Установка из локального каталога (`install_bundle <dir>`) — путь для разработчиков; обычные пользователи так не устанавливают; перед удалением плагина сделайте резервную копию каталога.
- `npm test` запускает три офлайн-набора: конфигурация/разбор/тайм-аут, подключение перехвата отправки и переключателя для каждой беседы (включая состояние баннера паузы), а также локальный сайдкар.
